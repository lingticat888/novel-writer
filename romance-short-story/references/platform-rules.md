## 主要平台对比

### 番茄小说
- **定位**：免费阅读，广告变现
- **字数要求**：短篇3万-10万字
- **核心指标**：完读率 > 追更率 > 点击率
- **推荐机制**：算法主导，完读率决定生死
- **风格偏好**：节奏快、爽点密、不费脑
- **禁忌**：慢热、大段心理描写、复杂叙事
- **稿费模式**：千字3-30元（签约），或分成

### 七猫小说
- **定位**：免费阅读，广告变现
- **字数要求**：短篇3万-8万字
- **核心指标**：同番茄，完读率为王
- **推荐机制**：算法+编辑推荐
- **风格偏好**：更偏甜宠/轻松向，虐后甜要足
- **禁忌**：纯虐无甜、结局太虐
- **稿费模式**：千字5-50元（签约），或分成

### 晋江文学城
- **定位**：付费阅读，精品向
- **字数要求**：短篇1万-5万字
- **核心指标**：收藏/评论/营养液
- **推荐机制**：编辑推荐+读者互动
- **风格偏好**：文笔有质感、人物有深度、虐要有逻辑
- **禁忌**：流水账、无逻辑爽、三观不正
- **稿费模式**：读者付费分成

### 知乎盐言故事
- **定位**：付费短篇，高质量
- **字数要求**：1万-3万字
- **核心指标**：点赞率 > 完读率 > 评论
- **推荐机制**：内容质量+社交传播
- **风格偏好**：有思考深度、反转精巧、文笔过关
- **禁忌**：套路化严重、文笔粗糙
- **稿费模式**：单篇买断/分成，千字50-200元

### 投稿建议
| 目标 | 推荐平台 | 原因 |
|------|----------|------|
| 新手练笔 | 番茄/七猫 | 门槛低，反馈快 |
| 有文笔追求 | 晋江/知乎 | 稿费高，读者质量好 |
| 追妻火葬场 | 番茄/七猫 | 该题材在这两个平台数据最好 |
| 想做IP改编 | 晋江 | IP开发链条最成熟 |

## 平台审核红线

### 全平台通用红线
1. **涉政内容**：禁止涉及政治人物/事件/评论
2. **色情描写**：禁止详细性描写，可暗示不可直写
3. **暴力血腥**：禁止详细暴力描写，特别是虐童/家暴
4. **违法内容**：毒品/赌博/洗钱等
5. **歧视内容**：性别/种族/地域歧视
6. **自杀描写**：禁止详细描写自杀方法，可写情绪不可写手段
7. **未成年人**：涉及未成年人恋爱/亲密关系

### 追妻火葬场题材特别注意事项
1. **虐女不能太具体**：家暴场景要模糊处理，重点写情绪而非动作
2. **离婚程序要合法**：涉及法律程序需基本合规
3. **不能美化犯罪**：男主如果做了违法的事，必须有法律后果
4. **精神控制要标注**：如果有PUA情节，结局必须否定这种行为
5. **复仇不能过线**：女主的反击要在法律/道德允许范围内

### 敏感词规避
| 敏感类别 | 原词 | 替代方案 |
|----------|------|----------|
| 暴力 | 打/扇/踹 | "他动了手"/"他失控了" |
| 性 | 具体描写 | "那一夜"/"他越了界"/留白 |
| 死亡 | 自杀/杀 | "离开这个世界"/"消失" |
| 毒品 | 吸毒 | 不写 |
| 精神病 | 抑郁症/PTSD | "她病了"/"她需要看医生" |

## 付费卡点设计

### 卡点本质

卡点不是"故事自然分段的地方"，是**读者被勾住不得不看下一章的锁扣**。免费章节的任务是让读者上瘾，卡点的任务是让瘾发作的那一刻刚好要付钱。

**卡点的底层逻辑**：
```
读者在阅读时一直在做判断："下一章值不值得看？"
→ 如果读者判断"值得"，他会翻页
→ 如果读者判断"不值得"，他关掉走了
→ 卡点就是在这个判断发生的瞬间，把"答案"藏到下一章
→ 读者付的不是内容的钱，是"知道答案"的钱
```

### 卡点技术：断章法

**断章 = 在情绪最浓的时候切断，而不是在情节结束的时候切断。**

| 断法 | 机制 | 示例 |
|------|------|------|
| **悬念断** | 抛出一个问题，不给答案 | 他推开门看到我，他的表情——我从来没见过那种表情。不是愤怒，不是冷漠，是——（断） |
| **反转断** | 刚出现一个意外，还没来得及消化 | 我以为他来找我是要带我回去。直到我看到他身后跟着的人——是许道陵。他带了许道陵来。（断） |
| **冲突断** | 两个人正面对峙，话说到一半 | "你到底想怎样？"我问。他沉默了很久，然后说了一句让我完全没想到的话——（断） |
| **信息差断** | 读者知道但角色不知道的信息刚要暴露 | 他不知道我听到了他和许道陵的对话。他不知道我知道那个"保质期"。他走过来的时候，我的手已经握住了剪刀——（断） |
| **选择断** | 角色面临两难选择，还没做决定 | 他跪在我面前，说"你开条件"。我的手摸到了口袋里那张机票——明天的，飞往任何一个他找不到的地方。我看着他，我还没想好——（断） |

**断章的绝对禁忌**：
- 不能在平淡处断（读者没有动力翻页）
- 不能在已有答案处断（读者已经满足了，不需要下一章）
- 不能在抽象情绪处断（"我的心很乱"——读者不关心）
- 不能欺骗断（暗示的事下一章没兑现——读者会愤怒弃文）

### 卡点位置规划（按平台）

**番茄小说（免费+广告模式）**：
番茄没有付费卡点，但有"留存卡点"——每一章结尾都必须让读者翻到下一章，因为完读率=推荐=收入。

```
每章800-2000字，章章断在钩子上
不是只有大卡点要断，每一章都要断
断法轮换：悬念断→反转断→冲突断→信息差断→循环
不能连续两章用同一种断法，读者会疲劳
```

**番茄短篇的章节节奏**（以5万字、每章1500字、约33章为例）：
```
第1章：开篇钩子+悬念断（我的处境是什么）
第2-5章：建立关系+冲突断（他做了什么让我动摇）
第6-10章：伤害递进+反转断/信息差断（真相的碎片）
第11-13章：清算+选择断（我要不要走）
第14章：逃离+悬念断（我走了，然后呢）
第15-18章：独立生活+反转断（他找到我了）
第19-22章：追妻拉扯+冲突断（他求我，我拒）
第23-25章：外部危机+选择断（不得不合作）
第26-28章：他崩溃+信息差断（他做了什么我不知道的事）
第29-31章：终极打脸+反转断
第32-33章：和解+收束（不断章，给读者满足感）
```

**七猫小说**：同番茄逻辑，完读率为王。

**晋江/知乎（付费模式）**：
```
免费章节（前20-30%）：密集虐点+强钩子，让读者产生"我必须看她翻身"的执念
付费卡点1：女主心死/离开（读者必须知道她怎么活下来）
付费卡点2：男主发现真相/崩溃（读者必须看他痛）
付费章节（后70-80%）：爽点密集兑现
注意：付费后的第一章必须立刻给出一个爽点，不能让读者觉得"付了钱还是虐"
```

## 章末钩子写法

### 钩子是商业短篇的命脉

**章末钩子 = 读者翻到下一章的理由。** 没有钩子的章节就是弃文点。商业短篇的读者是在碎片时间里看小说的——通勤、排队、睡前，每一章结尾都是他放下手机的时刻。钩子决定他是"放下手机"还是"再看一章"。

### 钩子强度等级

| 强度 | 类型 | 读者反应 | 适用频率 |
|------|------|---------|---------|
| 致命钩 | 重大反转/真相暴露/生死 | 不看下一章睡不着 | 每5000-8000字用一次 |
| 强钩 | 冲突升级/意外出现/关系突变 | 忍不住翻页 | 每2000-3000字用一次 |
| 中钩 | 悬念/疑问/信息差 | 好奇下一章 | 每章结尾 |
| 弱钩 | 情绪余韵/细节暗示 | 可翻可不翻 | 尽量少用，不能连续 |

**致命钩和强钩必须有画面**，不能是抽象的情绪。"我听到他说了一个让我心碎的词"不是钩子，是废话；"他说'保质期'——我的保质期"是钩子。

### 章末钩子模板库

**悬念型**（最常用，每2-3章用一个）：
```
[一个动作/事件刚发生] + [结果还没出来] + 断
示例：他推开门的那一刻，我的手刚好摸到窗框——（断）
```

**反转型**（冲击力最强，少用才有效）：
```
[读者预期A] + [实际发生B] + 断
示例：我以为他来带我回去。但他跪下了——不是求我回去，是求我收下那个信封。信封里是他妈的诊断书。（断）
```

**信息差型**（第一人称专用，"我"知道他不知道）：
```
[我发现了一个他不知道我知道的事] + [我决定怎么做还没说] + 断
示例：他不知道我听到了他跟许道陵的整段对话。他不知道"保质期"这个词我听得清清楚楚。他向我走过来的时候，我笑了——（断）
```

**冲突型**（正面对峙的瞬间）：
```
[两方正面碰撞] + [话说到关键处] + 断
示例：他拦在我面前，说"你不能走"。我看着他的手——那只手刚才还在接符纸。我说："让开。"他的手没动。（断）
```

**选择型**（角色面临决定）：
```
[两个选项] + [还没选] + 断
示例：桌上摆着两样东西：一张回他身边的合同，一张明天的机票。他看着我，等我选。我伸手拿的是——（断）
```

### 钩子使用的铁律

1. **每一章必须以钩子结尾**：没有例外。哪怕这章很爽很满足，结尾也要埋一个新钩子——满足感是暂时的，好奇心是持续的
2. **钩子必须下一章兑现**：不能骗读者。你在章末抛出的悬念，下一章必须给出答案或推进，不能悬三章不管
3. **致命钩不能连续用**：连着两章都是重大反转，读者会麻木。致命钩之后接一个喘息章（但有中钩），再接强钩
4. **钩子要有画面**：所有钩子都必须是具体的动作/事件/对话，不能是抽象情绪
5. **免费章节的钩子要比付费章节更狠**：免费区是获客，钩子要狠到读者无法拒绝；付费区是履约，爽点要密但钩子可以稍缓

## 算法推荐逻辑

### 通用推荐算法因素
1. **点击率**（标题+封面的吸引力）
2. **完读率**（内容留存力，权重最高）
3. **追更率**（读者粘性）
4. **互动率**（评论/收藏/分享）
5. **阅读时长**（沉浸度）

### 提升完读率的关键
- 开头300字必须有冲突/悬念
- 每1000字至少一个情绪波动点
- 付费前内容要足够虐，让读者产生"我必须看她翻身"的执念
- 付费后爽点要密集兑现
- 结尾要干净利落，不要拖泥带水

### 提升点击率的关键
- 标题包含核心标签词（追妻火葬场/替身/离婚/打脸）
- 导语展示最爽/最虐片段
- 标题格式参考：[核心冲突] + [反转预告]

## 商业化写作检查清单

创作完成后，逐项检查：

### 导语/标题
- [ ] 标题包含2个以上热门标签词
- [ ] 导语200字以内
- [ ] 导语有对话或具体动作
- [ ] 导语有反转/悬念
- [ ] 导语情绪浓度高

### 开头
- [ ] 前300字有第一个钩子
- [ ] 前1000字有核心冲突
- [ ] 前3000字建立女主同情+男主冷漠

### 节奏
- [ ] 每800-1500字有小钩子
- [ ] 每2000-3000字有中爽点
- [ ] 每5000-8000字有大爽点
- [ ] 虐女阶段不超过全文40%
- [ ] 没有超过2000字的情绪平淡区

### 人设
- [ ] 女主前期值得同情，后期值得追捧
- [ ] 男主前期足够渣，后期足够痛
- [ ] 白月光/绿茶结局得到惩罚
- [ ] 男二真心好但女主不选

### 结局
- [ ] HE或条件性和解
- [ ] 女主不轻易原谅
- [ ] 男主付出了足够代价
- [ ] 读者情绪得到释放

### 合规
- [ ] 无敏感内容
- [ ] 虐待场景模糊处理
- [ ] 法律程序基本合规
- [ ] 无美化违法行为
