## 主要平台对比

### 番茄小说
- **定位**：免费阅读，广告变现
- **字数要求**：短篇3万-10万字
- **核心指标**：完读率 > 追更率 > 点击率
- **推荐机制**：算法主导，完读率决定生死
- **风格偏好**：节奏快、爽点密、不费脑
- **禁忌**：慢热、大段心理描写、复杂叙事
- **稿费模式**：千字3-30元（签约），或分成

### 七猫小说
- **定位**：免费阅读，广告变现
- **字数要求**：短篇3万-8万字
- **核心指标**：同番茄，完读率为王
- **推荐机制**：算法+编辑推荐
- **风格偏好**：更偏甜宠/轻松向，虐后甜要足
- **禁忌**：纯虐无甜、结局太虐
- **稿费模式**：千字5-50元（签约），或分成

### 晋江文学城
- **定位**：付费阅读，精品向
- **字数要求**：短篇1万-5万字
- **核心指标**：收藏/评论/营养液
- **推荐机制**：编辑推荐+读者互动
- **风格偏好**：文笔有质感、人物有深度、虐要有逻辑
- **禁忌**：流水账、无逻辑爽、三观不正
- **稿费模式**：读者付费分成

### 知乎盐言故事
- **定位**：付费短篇，高质量
- **字数要求**：1万-3万字
- **核心指标**：点赞率 > 完读率 > 评论
- **推荐机制**：内容质量+社交传播
- **风格偏好**：有思考深度、反转精巧、文笔过关
- **禁忌**：套路化严重、文笔粗糙
- **稿费模式**：单篇买断/分成，千字50-200元

### 投稿建议
| 目标 | 推荐平台 | 原因 |
|------|----------|------|
| 新手练笔 | 番茄/七猫 | 门槛低，反馈快 |
| 有文笔追求 | 晋江/知乎 | 稿费高，读者质量好 |
| 追妻火葬场 | 番茄/七猫 | 该题材在这两个平台数据最好 |
| 想做IP改编 | 晋江 | IP开发链条最成熟 |

## 平台审核红线

### 全平台通用红线
1. **涉政内容**：禁止涉及政治人物/事件/评论
2. **色情描写**：禁止详细性描写，可暗示不可直写
3. **暴力血腥**：禁止详细暴力描写，特别是虐童/家暴
4. **违法内容**：毒品/赌博/洗钱等
5. **歧视内容**：性别/种族/地域歧视
6. **自杀描写**：禁止详细描写自杀方法，可写情绪不可写手段
7. **未成年人**：涉及未成年人恋爱/亲密关系

### 追妻火葬场题材特别注意事项
1. **虐女不能太具体**：家暴场景要模糊处理，重点写情绪而非动作
2. **离婚程序要合法**：涉及法律程序需基本合规
3. **不能美化犯罪**：男主如果做了违法的事，必须有法律后果
4. **精神控制要标注**：如果有PUA情节，结局必须否定这种行为
5. **复仇不能过线**：女主的反击要在法律/道德允许范围内

### 敏感词规避
| 敏感类别 | 原词 | 替代方案 |
|----------|------|----------|
| 暴力 | 打/扇/踹 | "他动了手"/"他失控了" |
| 性 | 具体描写 | "那一夜"/"他越了界"/留白 |
| 死亡 | 自杀/杀 | "离开这个世界"/"消失" |
| 毒品 | 吸毒 | 不写 |
| 精神病 | 抑郁症/PTSD | "她病了"/"她需要看医生" |

## 付费卡点设计

### 卡点原则
付费卡点设在**读者最忍不住要看下去**的地方，而非故事自然分段处。

### 最佳卡点位置
1. **真相即将揭开**：读者知道答案就在下一章
2. **女主即将打脸**：反击已蓄势待发
3. **男主刚刚崩溃**：他的反应是什么
4. **身份即将揭晓**：女主真面目即将曝光
5. **生死悬念**：有人面临危险

### 最差卡点位置（绝对不要用）
1. 平淡过渡段落
2. 已解决冲突后
3. 大段环境描写
4. 角色内心独白中段
5. 配角戏份中段

### 卡点参考位置（以3万字为例）
```
免费章节：前8000-12000字（建立代入感+触发虐点）
第一卡点：女主心死/离开（读者必须知道她怎么活下来）
第二卡点：男主发现真相（读者必须看他崩溃）
第三卡点：追妻高潮前（读者必须看打脸）
付费章节：12000-30000字（爽点密集区）
```

## 算法推荐逻辑

### 通用推荐算法因素
1. **点击率**（标题+封面的吸引力）
2. **完读率**（内容留存力，权重最高）
3. **追更率**（读者粘性）
4. **互动率**（评论/收藏/分享）
5. **阅读时长**（沉浸度）

### 提升完读率的关键
- 开头300字必须有冲突/悬念
- 每1000字至少一个情绪波动点
- 付费前内容要足够虐，让读者产生"我必须看她翻身"的执念
- 付费后爽点要密集兑现
- 结尾要干净利落，不要拖泥带水

### 提升点击率的关键
- 标题包含核心标签词（追妻火葬场/替身/离婚/打脸）
- 导语展示最爽/最虐片段
- 标题格式参考：[核心冲突] + [反转预告]

## 商业化写作检查清单

创作完成后，逐项检查：

### 导语/标题
- [ ] 标题包含2个以上热门标签词
- [ ] 导语200字以内
- [ ] 导语有对话或具体动作
- [ ] 导语有反转/悬念
- [ ] 导语情绪浓度高

### 开头
- [ ] 前300字有第一个钩子
- [ ] 前1000字有核心冲突
- [ ] 前3000字建立女主同情+男主冷漠

### 节奏
- [ ] 每800-1500字有小钩子
- [ ] 每2000-3000字有中爽点
- [ ] 每5000-8000字有大爽点
- [ ] 虐女阶段不超过全文40%
- [ ] 没有超过2000字的情绪平淡区

### 人设
- [ ] 女主前期值得同情，后期值得追捧
- [ ] 男主前期足够渣，后期足够痛
- [ ] 白月光/绿茶结局得到惩罚
- [ ] 男二真心好但女主不选

### 结局
- [ ] HE或条件性和解
- [ ] 女主不轻易原谅
- [ ] 男主付出了足够代价
- [ ] 读者情绪得到释放

### 合规
- [ ] 无敏感内容
- [ ] 虐待场景模糊处理
- [ ] 法律程序基本合规
- [ ] 无美化违法行为
