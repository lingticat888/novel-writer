## 核心差异：商业短篇 vs 传统文学

女频商业短篇小说与传统文学在底层逻辑上完全不同，这决定了从选题到写法的全流程差异。

### 创作目的不同
| 维度 | 传统文学 | 商业短篇 |
|------|----------|----------|
| 目的 | 艺术表达/思想深度 | 情绪商品/即时满足 |
| 读者关系 | 作者引导读者 | 读者需求驱动 |
| 评价标准 | 文学性/深度/原创性 | 爽感/代入感/付费转化 |
| 创作逻辑 | 人物驱动，自然生长 | 爽点驱动，逆向设计 |

### 结构逻辑不同
- **传统文学**：起承转合，缓慢铺垫，高潮在后
- **商业短篇**：前置高潮，持续输出，每300字一个爽点/钩子

### 人设逻辑不同
- **传统文学**：人物复杂多面，有成长弧线
- **商业短篇**：人物标签化、极端化，服务于情绪功能

## 读者画像与消费心理

### 核心读者群
- **性别**：85%以上为女性
- **年龄**：18-35岁为主力
- **消费场景**：碎片化阅读，通勤/睡前/午休
- **单次阅读时长**：15-45分钟

### 心理需求层次
1. **情感补偿**：现实中缺失的被重视、被偏爱、被追捧
2. **情绪宣泄**：压抑的愤怒、委屈需要一个出口
3. **权力幻想**：从被动到主动的逆转体验
4. **道德满足**：恶人受罚、好人翻身的正义感

### 阅读行为特征
- **3秒定生死**：标题/封面决定是否点击
- **前300字定存留**：开头必须抓住，否则直接划走
- **付费卡点极度敏感**：卡在情绪最饱满处
- **完读率决定推荐**：平台算法最看重完读率

## 商业短篇小说的基本参数

### 篇幅规格
| 平台 | 字数范围 | 章节划分 | 每章字数 |
|------|----------|----------|----------|
| 番茄小说 | 3万-10万字 | 20-50章 | 800-2000字 |
| 七猫小说 | 3万-8万字 | 20-40章 | 1000-2000字 |
| 晋江文学城 | 1万-5万字 | 10-30章 | 1000-3000字 |
| 知乎盐言 | 1万-3万字 | 5-15章 | 1000-2000字 |

### 价格体系
- 免费阅读平台（番茄/七猫）：广告变现，完读率=收入
- 付费阅读平台（晋江/知乎）：章节付费，卡点=收入
- 单篇稿费市场价：300-2000元/万字（签约作者）

## 关键术语表

| 术语 | 定义 |
|------|------|
| 爽点 | 让读者获得情绪满足的情节点，是商业小说的核心单元 |
| 钩子 | 悬念或冲突，牵引读者继续阅读的机制 |
| 打脸 | 之前被羞辱/轻视的角色反击成功，读者获得爽感 |
| 金手指 | 主角拥有的超常规优势/能力 |
| 追妻火葬场 | 男主前期虐女主，后期悔恨疯狂追回的叙事模式 |
| 导语 | 作品展示页的简介文案，决定读者是否点击阅读 |
| 卡点 | 付费章节的截止位置，必须设在情绪最紧张处 |
| 完读率 | 读者从头读到尾的比例，影响平台推荐权重 |
| 追更率 | 读者持续追读后续章节的比例 |
| 扒马甲 | 隐藏身份被揭穿的情节，制造反差爽感 |
| 虐女 | 前期对女主的情感伤害，为后期反转蓄力 |
| 虐男 | 后期对男主的惩罚性描写，满足读者的报复快感 |
| HE | Happy Ending，大团圆结局 |
| BE | Bad Ending，悲剧结局（商业短篇极少使用） |
| OE | Open Ending，开放式结局 |
| 先婚后爱 | 从婚姻开始发展感情的叙事模式 |
| 替身 | 女主被认为是另一个女人的替身，后期反转 |
| 白月光 | 男主心中不可替代的初恋/理想女性 |
| 绿茶 | 表面温柔实则心机的女性角色 |
| 霸总 | 霸道总裁，女频经典男性人设 |
