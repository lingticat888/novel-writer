## 题材核心逻辑

追妻火葬场的本质是**延迟满足型爽文**。读者忍受前期的虐，是为了兑换后期更强烈的爽。

### 情绪经济学公式
```
前期虐女（痛苦投资）→ 后期虐男（收益兑现）→ 爽感 = 虐的程度 x 反转力度
```

核心原则：
1. **虐得越深，爽得越狠**：前期情绪投资决定后期爽感天花板
2. **反转必须彻底**：从被无视到被跪求，地位必须180度翻转
3. **渣男必须真渣**：男主前期越不可原谅，后期追妻越有张力
4. **女主必须成长**：不是靠男主回头，而是靠自己翻盘

## 经典叙事结构

### 三幕式结构（适用于3-5万字短篇）

```
第一幕：虐女期（占全文30-40%）
├── 建立关系：女主对男主的深情/付出
├── 展现冷漠：他的忽视/轻贱/伤害（我怎么感受到的）
├── 催化事件：白月光回归/误会加深/怀孕被逼
└── 心死离开：我彻底放弃（最高虐点）

第二幕：觉醒期（占全文20-30%）
├── 我的蜕变：形象/能力/社交圈全面升级
├── 他发现真相：我观察到的他的反应（崩溃/失态/反常行为）
├── 追妻开始：他卑微求复合（我怎么应对）
└── 我的拒绝：痛快打脸，绝不轻易原谅

第三幕：火葬场（占全文30-40%）
├── 持续追妻：他越发卑微/疯狂/痛苦（我看到的和感受到的）
├── 二次打脸：当众表白/下跪/放弃一切（我的反应）
├── 终极考验：生死/大事件验证真心（我如何判断）
└── HE/条件和解：我设定门槛，他必须达到
```

### 五段式结构（适用于5-10万字中篇）

```
1. 甜蜜陷阱（10%）：短暂的假象甜蜜，对比后更虐
2. 持续虐女（30%）：他层层递进地伤害我，不断突破我的底线
3. 心死离场（10%）：我决绝离开，不给任何余地
4. 蜕变追妻（30%）：我的新生 + 他的火葬场（我从外部观察到的）
5. 高潮和解（20%）：极致打脸 + 我的条件性和解
```

## 人设体系

### 逻辑归因链（最高优先级规则）

**每一个角色的行为、每一个剧情转折，必须有完整的因果链支撑。** 不能靠"突然开悟""莫名心动""一拍脑门"来推动情节。

**归因链模板**：
```
角色行为 → 为什么这么做 → 根源是什么 → 这个根源是否合理
```

**检查方法**：对每个关键行为追问"为什么"，至少追问3层。如果追问到第3层答不出来或答不合理，说明这个行为没有逻辑支撑，必须重新设计。

**示例**：
- ❌ "男主追妻因为他突然发现自己爱女主" → 为什么突然发现？→ 没有理由 → 逻辑断裂
- ✅ "男主追妻因为他发现她的手再也画不了画了" → 为什么手画不了？→ 三年画符损耗 → 为什么他之前不在意？→ 他把她当工具 → 为什么现在在意了？→ 因为她走了之后他发现她在他生活中的痕迹无处不在，不只是"画符的痕迹"，是她煮的咖啡温度、她叠衣服的方式、她留的便签——这些东西他以为是功能性的，失去后才知道是"她" → 逻辑闭环

**追妻火葬场的核心归因链**：
```
男主前期渣 → 为什么渣？→ 必须有根源（不是纯坏，是认知缺陷/情感障碍/环境塑造）
男主后期追 → 为什么追？→ 必须有转折事件触发（不是突然开窍，是某个具体事件击碎了他的认知框架）
女主值得心疼 → 为什么心疼？→ 必须有具体的损失/伤害（不是被骗了感情，是失去了真实的东西）
女主后期蜕变 → 为什么能蜕变？→ 必须有支撑条件（不是突然变强，是有现实基础）
```

### 女主人设公式

追妻火葬场的女主必须经历**从弱到强**的转变，人设需要同时支撑"前期值得同情"和"后期值得追捧"。

**前期人设要素**（让"我"心疼）：
- 被迫而非自愿（不是恋爱脑自我感动，是被现实/胁迫/信息差所困）
- 有真实的损失（身体/时间/能力/尊严，不是"被骗了感情"这种轻飘飘的痛）
- 隐忍有逻辑（有她走不了的原因，不是傻，是别无选择）
- 哪怕困局中也有微光（不是完全被动，有自己的挣扎痕迹）

**后期人设要素**（让"我"向往）：
- 蜕变有现实基础（不是突然变强，是脱离控制后自然释放的能力）
- 情感独立（不再围绕男主转，有自己的生活重心）
- 明确底线（拒绝时干脆利落，不拖泥带水）
- 活出了"我"自己（从"为别人活"到"为自己活"）

**常见女主原型**：
| 原型 | 前期 | 后期 | 爽点来源 |
|------|------|------|----------|
| 被胁迫者 | 被抓住软肋不得不服从 | 软肋解除后果断离开 | 逃离的决绝 |
| 被消耗者 | 被榨取某种价值（才能/身体/命格） | 拒绝继续被消耗 | "我不欠你了" |
| 被蒙蔽者 | 被操控了认知，以为现状是正常的 | 认知框架被打碎后的清醒 | 清醒后的反击 |
| 被替代者 | 被当作另一个人的替身/工具 | 证明自己不可替代后选择不回头 | "你不配了" |

### 男主人设公式：渣苏法则

**追妻火葬场的男主必须是"渣苏"，不能是纯坏。**

纯坏没有追妻的心理基础——他坏到底就行了，何必追？追妻的前提是**他自己也被困在某种认知牢笼里**，他的渣有根源，他的苏有底色，他追是因为他终于分不清控制和爱的边界了。

**渣苏定义**：
- **渣** = 他的行为伤害了女主，这些伤害是真实的、不可否认的
- **苏** = 他身上存在让读者即使恨他也无法完全厌恶的东西——魅力、痛苦、真心、或某种让人心软的脆弱
- **渣苏一体** = 他的渣和苏不是分开的，是同一个人的两面。他的渣往往就是他的苏的来源

**渣苏的底层逻辑——他为什么渣？他为什么追？**

男主的渣必须有**认知根源**，不能是"他天生坏"或"他不懂爱"这么敷衍。常见的认知根源：

| 渣的认知根源 | 他怎么渣的 | 他为什么能追（苏的来源） | 追的心理动力 |
|-------------|-----------|----------------------|------------|
| **情感无能** | 能感知利益但感知不到爱，把关系当交易 | 他不是没有感情，是不知道自己在意就是爱。他的"维护""照顾"看似功利，实则是他唯一会表达爱的方式 | 她走了他才知道"维护"不是维护工具，是舍不得 |
| **控制型人格** | 需要掌控一切包括人，把控制等同于爱 | 他的控制欲来自深层的恐惧（失去=毁灭），他控制她是因为她对他太重要了，只是他不知道还有别的方式 | 她逃离让他第一次体验"无法控制"，这个恐慌逼他面对自己的恐惧 |
| **认知错位** | 真心认为自己的方式是对的（"我给你最好的"），意识不到这是伤害 | 他的出发点不是恶意，他的好和坏是一体的——同样的特质让他成功也让他伤人 | 某个事件击碎了他的认知框架，他发现自己笃信的"对"其实是"错" |
| **自我欺骗** | 一直在骗自己"我只是需要她"，拒绝承认动心 | 他在拒绝承认的过程中已经做了超出"需要"的事，这些矛盾行为就是苏 | 骗不下去了。她走了之后他没法再用"需要"解释自己为什么找她 |

**追妻的心理动力模型**：

追妻不能是"他突然发现爱她"，必须有**具体的心理转变事件+内在逻辑**：

```
转变前状态 → 击碎事件 → 认知崩塌 → 重建认知（这才知道是爱）→ 追
```

1. **转变前**：他有一套自洽的逻辑来解释自己的行为（"我需要她""这是交易""我对她够好了"）
2. **击碎事件**：某个具体事件让他这套逻辑解释不了了（不是抽象的"她走了"，是某个他无法自圆其说的细节）
3. **认知崩塌**：他发现自己做过的事里，有一些没法用"需要""交易"来解释——比如他半夜去看她睡着没有，比如他记得她爱吃什么是他主动问的不是她说的
4. **重建认知**：他被迫承认——那些"多余"的行为，是爱。他一直用功利的框架框住自己，框不住的那些溢出来的，就是真心
5. **追**：他追不是因为"我错了"（那是道歉），是因为"我终于知道了"——知道自己一直爱着却不敢认，知道自己亲手把人推走了

**渣苏人设的绝对禁忌**：
1. **不能纯坏**：没有苏的渣是反派，不配追妻
2. **不能纯好**：没有渣的苏是暖男，不需要追妻
3. **渣不能没有根源**：天生坏=没有转变可能=追妻不成立
4. **追不能没有触发**：突然开窍=没有逻辑=读者不信
5. **苏不能抵消渣**：他有真心不代表他的伤害不存在，女主不欠他原谅
6. **不能只剩道歉**：道歉太轻，追妻要用行动和代价来偿还，不是几句"我错了"

**常见男主原型**：
| 原型 | 渣的表现 | 苏的底色 | 追的触发 |
|------|---------|---------|---------|
| 情感无能者 | 把她当工具，温柔也是功能性的 | 他不知道自己已经在用"爱的方式"对她——守夜、记住习惯、不忍换人 | 她走后他发现自己做的事里有很多"多出来的"部分，这些不是功能需求能解释的 |
| 控制型 | 用手段留人，用温柔包装控制 | 他的控制来自恐惧，不是恶意。他太怕失去所以攥太紧 | 她的逃离让他体验了真正的失去，他发现自己宁可她自由也不要失去她 |
| 认知错位者 | 真心认为自己对她好，看不到伤害 | 他的好是真实的，只是方式错了。他在用自己认为对的方式爱，但那不是她需要的 | 他看到她离开后的真实状态（手废了/人变了），才知道自己给的不是爱是害 |
| 自我欺骗者 | 一直对自己说"我只是需要她" | 他已经在"需要"之外做了太多多余的事，这些矛盾就是苏 | 她走了以后他找不到"需要"的替代品——不是因为功能不可替代，是因为她不可替代 |

## 导语写法

导语是商业短篇的**生死线**，决定读者是否点击。

### 导语的商业逻辑
- 导语不是简介，是**情绪钩子**
- 不讲完整故事，只展示**最爽的片段或最虐的冲突**
- 让读者在3秒内产生"我要看这个"的冲动

### 导语公式

**公式一：对话切入式**（最常见、转化率最高）
```
[我决绝的话] + [男主的反应/意外] + [悬念钩子]
```
示例：
> "离婚协议签好了，别再找我。"
> 他以为我又在闹脾气，直到三个月后，在别人的订婚宴上，他看到我笑靥如花。
> 我身边站着的男人，是他这辈子都高攀不起的存在。

**公式二：情境反差式**
```
[我的卑微处境] + [令人震惊的转折] + [地位翻转预告]
```
示例：
> 结婚三年，他叫我"替身"。
> 我以为自己只是白月光的影子，直到我离开那天——
> 整个京城都在找我，而我，才是他真正的白月光。

**公式三：时间紧迫式**
```
[紧迫情境] + [两难选择] + [情绪爆发点]
```
示例：
> 我在产房里生死一线，他在白月光身边温柔陪伴。
> 签下离婚协议的那一刻，我带走了所有属于他的东西——
> 包括那个他永远不可能知道的孩子。

### 导语铁律
1. **不超过200字**：3秒看完，5秒决定
2. **必须有人物对话或动作**：纯叙述没有冲击力
3. **至少一个反转/悬念**：让读者好奇"然后呢"
4. **情绪浓度要高**：要么虐到心碎，要么爽到飞起
5. **绝对不要剧透结局**：暗示但不说破

## 钩子与爽点设计

### 钩子类型库

| 钩子类型 | 机制 | 示例 |
|----------|------|------|
| 悬念钩 | 抛出未解之谜 | "我摘下墨镜，迎上他震惊的目光——他记忆里的那张脸，根本不是我的。" |
| 冲突钩 | 制造正面碰撞 | "白月光端起咖啡泼向我，我笑了。" |
| 反转钩 | 打破读者预期 | "所有人都以为我是来求复合的，只有我知道，这是最后的告别。" |
| 情感钩 | 直击情绪软肋 | "他终于说了那句我等了三年的话，可我已经不在乎了。" |
| 信息差钩 | 我知道他不知道 | "他不知道，他嘴里念着的那个名字，已经在户口本上被划掉了。" |

### 爽点类型库

| 爽点类型 | 触发机制 | 强度 |
|----------|----------|------|
| 当众打脸 | 女主在众人面前展现实力/身份 | ★★★★★ |
| 男主卑微 | 男主下跪/哭泣/哀求 | ★★★★★ |
| 白月光翻车 | 白月光真面目被揭穿 | ★★★★☆ |
| 身份碾压 | 女主真实身份/能力远超众人想象 | ★★★★☆ |
| 嫉妒发狂 | 男主看到女主和男二在一起 | ★★★★☆ |
| 语言反击 | 女主用最冷静的话说最扎心的话 | ★★★★☆ |
| 实力碾压 | 女主在专业/社交/商业上远超对手 | ★★★☆☆ |
| 众人震惊 | 旁观者对女主/男主变化的反应 | ★★★☆☆ |

### 爽点分布节奏
```
每800-1500字：至少一个小钩子（悬念/小冲突）
每2000-3000字：至少一个中爽点（打脸/反转）
每5000-8000字：至少一个大爽点（身份揭露/当众打脸/男主崩溃）
付费卡点前：必须是情绪最高潮或最大悬念
```

## 节奏控制

### 短篇节奏铁律

1. **300字法则**：开头300字内必须有第一个钩子
2. **无废话原则**：每个段落要么推情节，要么蓄情绪，否则删
3. **信息密度优先**：一句话能说清的不用两句
4. **情绪曲线不可平**：任何连续1000字内不能没有情绪波动

### 情绪曲线设计

```
虐女阶段情绪曲线（蓄力）：
高 ┃     ╱╲    ╱╲
   ┃    ╱  ╲  ╱  ╲     ╱← 最后一次伤害
   ┃   ╱    ╲╱    ╲   ╱
   ┃  ╱           ╲ ╱
低 ┃╱              ← 开始的甜蜜假象
   ┗━━━━━━━━━━━━━━━━━

追妻阶段情绪曲线（释放）：
高 ┃              ╱╲   ╱╲   ╱← 最高潮打脸
   ┃        ╱╲  ╱  ╲ ╱  ╲ ╱
   ┃  ╱╲  ╱  ╲╱    ╳    ╲
   ┃ ╱  ╲╱            ╲  ╲
低 ┃╱ 蜕变             ← 男主开始后悔
   ┗━━━━━━━━━━━━━━━━━
```

### 关键节奏节点（以3万字短篇为例）

| 节点 | 位置 | 内容 | 情绪 |
|------|------|------|------|
| 钩子开头 | 前300字 | 展示"我"的冲突/反差 | 好奇 |
| 关系建立 | 1000-3000字 | 我的付出与被忽视 | 心疼 |
| 第一次伤害 | 3000-5000字 | 他对我的冷漠/偏心 | 愤怒 |
| 伤害升级 | 5000-9000字 | 层层递进地虐我 | 积压 |
| 心死时刻 | 9000-12000字 | 我彻底放弃 | 心碎 |
| 蜕变开始 | 12000-15000字 | 我转身变强 | 期待 |
| 真相揭开 | 15000-18000字 | 我看到他的反常/崩溃反应 | 痛快 |
| 追妻打脸 | 18000-25000字 | 我的持续打脸+他追我 | 爽 |
| 终极高潮 | 25000-28000字 | 最大的打脸/他最卑微的时刻 | 极爽 |
| 和解/HE | 28000-30000字 | 我给出条件性和解 | 满足 |

## 常见变体与组合

### 题材组合公式

追妻火葬场可与其他热门标签组合，形成差异化：

| 组合 | 核心卖点 | 差异化点 |
|------|----------|----------|
