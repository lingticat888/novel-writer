## 题材核心逻辑

追妻火葬场的本质是**延迟满足型爽文**。读者忍受前期的虐，是为了兑换后期更强烈的爽。

### 情绪经济学公式
```
前期虐女（痛苦投资）→ 后期虐男（收益兑现）→ 爽感 = 虐的程度 x 反转力度
```

核心原则：
1. **虐得越深，爽得越狠**：前期情绪投资决定后期爽感天花板
2. **反转必须彻底**：从被无视到被跪求，地位必须180度翻转
3. **渣男必须真渣**：男主前期越不可原谅，后期追妻越有张力
4. **女主必须成长**：不是靠男主回头，而是靠自己翻盘

## 经典叙事结构

### 三幕式结构（适用于3-5万字短篇）

```
第一幕：虐女期（占全文30-40%）
├── 建立关系：女主对男主的深情/付出
├── 展现冷漠：他的忽视/轻贱/伤害（我怎么感受到的）
├── 催化事件：白月光回归/误会加深/怀孕被逼
└── 心死离开：我彻底放弃（最高虐点）

第二幕：觉醒期（占全文20-30%）
├── 我的蜕变：形象/能力/社交圈全面升级
├── 他发现真相：我观察到的他的反应（崩溃/失态/反常行为）
├── 追妻开始：他卑微求复合（我怎么应对）
└── 我的拒绝：痛快打脸，绝不轻易原谅

第三幕：火葬场（占全文30-40%）
├── 持续追妻：他越发卑微/疯狂/痛苦（我看到的和感受到的）
├── 二次打脸：当众表白/下跪/放弃一切（我的反应）
├── 终极考验：生死/大事件验证真心（我如何判断）
└── HE/条件和解：我设定门槛，他必须达到
```

### 五段式结构（适用于5-10万字中篇）

```
1. 甜蜜陷阱（10%）：短暂的假象甜蜜，对比后更虐
2. 持续虐女（30%）：他层层递进地伤害我，不断突破我的底线
3. 心死离场（10%）：我决绝离开，不给任何余地
4. 蜕变追妻（30%）：我的新生 + 他的火葬场（我从外部观察到的）
5. 高潮和解（20%）：极致打脸 + 我的条件性和解
```

## 人设体系

### 女主人设公式

追妻火葬场的女主必须经历**从弱到强**的转变，人设需要同时支撑"前期值得同情"和"后期值得追捧"。

**前期人设要素**（让人心疼）：
- 深情但不卑微（有尊严的付出，不是无脑舔）
- 有被忽视的闪光点（读者知道她值得更好）
- 隐忍有原因（为爱/为孩子/为承诺）
- 关键时刻的倔强（暗示内在力量）

**后期人设要素**（让人向往）：
- 形象蜕变（外貌/气质/社交地位）
- 能力觉醒（被隐藏的才华/身份）
- 情感独立（不再围着男主转）
- 明确底线（拒绝时干脆利落）

**常见女主原型**：
| 原型 | 前期 | 后期 | 爽点来源 |
|------|------|------|----------|
| 隐忍妻子 | 默默付出的豪门妻 | 恢复真身的千金/天才 | 身份反差 |
| 替身情人 | 被当作白月光替身 | 本尊归来/比白月光更优秀 | 身份碾压 |
| 暗恋少女 | 多年暗恋被无视 | 华丽转身让他高攀不起 | 地位反转 |
| 错嫁之妻 | 被当成联姻工具 | 展现不可替代的价值 | 价值觉醒 |

### 男主人设公式

追妻火葬场的男主必须经历**从高高在上到卑微求而不得**的转变。

**前期人设要素**（让人恨但不是纯反派）：
- 有魅力的渣（帅/有能力/有地位，不是纯废物）
- 冷漠有逻辑（不是无理取闹，是有"理由"的忽视）
- 存在误解基础（信息差/偏听偏信/情感未开蒙）
- 微妙的在意（不经意流露的关注，暗示感情基础）

**后期人设要素**（让人解气又心动）：
- 自我打脸（亲口承认前期的错）
- 放下身段（从高高在上到卑微求恳）
- 痛苦具象化（失眠/消瘦/酗酒/失控）
- 用行动证明（不是嘴上说说，是实打实的改变）

**常见男主原型**：
| 原型 | 前期冷漠表现 | 后期追妻方式 |
|------|-------------|-------------|
| 冰山霸总 | 情感缺位，视婚姻为契约 | 情感开蒙后失控，用资源疯狂追 |
| 误会男主 | 因白月光/误会伤害女主 | 真相揭开后崩溃，自罚式追妻 |
| 迟钝男主 | 一直不知道自己已爱上 | 意识到时已晚，疯狂弥补 |
| 傲慢少爷 | 自以为是，高高在上 | 被现实打碎骄傲，跪着求 |
| 渣男回头 | 多次伤害，不珍惜 | 用极端代价证明真心 |

### 关键配角功能

| 角色功能 | 作用 | 设计要点 |
|----------|------|----------|
| 白月光 | 前期制造误会/伤害的由头 | 必须有反转，要么绿茶要么不如女主 |
| 绿茶/恶女 | 制造矛盾/推进虐点 | 结局必须被惩罚，不能善了 |
| 男二 | 追妻期的催化剂，让男主嫉妒 | 必须真心对女主好，形成对比 |
| 闺蜜/助攻 | 女主蜕变的支持系统 | 替读者骂男主/推动情节 |
| 长辈 | 增加矛盾/阻碍的工具 | 可以是施虐者也可以是关键反转 |

## 导语写法

导语是商业短篇的**生死线**，决定读者是否点击。

### 导语的商业逻辑
- 导语不是简介，是**情绪钩子**
- 不讲完整故事，只展示**最爽的片段或最虐的冲突**
- 让读者在3秒内产生"我要看这个"的冲动

### 导语公式

**公式一：对话切入式**（最常见、转化率最高）
```
[我决绝的话] + [男主的反应/意外] + [悬念钩子]
```
示例：
> "离婚协议签好了，别再找我。"
> 他以为我又在闹脾气，直到三个月后，在别人的订婚宴上，他看到我笑靥如花。
> 我身边站着的男人，是他这辈子都高攀不起的存在。

**公式二：情境反差式**
```
[我的卑微处境] + [令人震惊的转折] + [地位翻转预告]
```
示例：
> 结婚三年，他叫我"替身"。
> 我以为自己只是白月光的影子，直到我离开那天——
> 整个京城都在找我，而我，才是他真正的白月光。

**公式三：时间紧迫式**
```
[紧迫情境] + [两难选择] + [情绪爆发点]
```
示例：
> 我在产房里生死一线，他在白月光身边温柔陪伴。
> 签下离婚协议的那一刻，我带走了所有属于他的东西——
> 包括那个他永远不可能知道的孩子。

### 导语铁律
1. **不超过200字**：3秒看完，5秒决定
2. **必须有人物对话或动作**：纯叙述没有冲击力
3. **至少一个反转/悬念**：让读者好奇"然后呢"
4. **情绪浓度要高**：要么虐到心碎，要么爽到飞起
5. **绝对不要剧透结局**：暗示但不说破

## 钩子与爽点设计

### 钩子类型库

| 钩子类型 | 机制 | 示例 |
|----------|------|------|
| 悬念钩 | 抛出未解之谜 | "我摘下墨镜，迎上他震惊的目光——他记忆里的那张脸，根本不是我的。" |
| 冲突钩 | 制造正面碰撞 | "白月光端起咖啡泼向我，我笑了。" |
| 反转钩 | 打破读者预期 | "所有人都以为我是来求复合的，只有我知道，这是最后的告别。" |
| 情感钩 | 直击情绪软肋 | "他终于说了那句我等了三年的话，可我已经不在乎了。" |
| 信息差钩 | 我知道他不知道 | "他不知道，他嘴里念着的那个名字，已经在户口本上被划掉了。" |

### 爽点类型库

| 爽点类型 | 触发机制 | 强度 |
|----------|----------|------|
| 当众打脸 | 女主在众人面前展现实力/身份 | ★★★★★ |
| 男主卑微 | 男主下跪/哭泣/哀求 | ★★★★★ |
| 白月光翻车 | 白月光真面目被揭穿 | ★★★★☆ |
| 身份碾压 | 女主真实身份/能力远超众人想象 | ★★★★☆ |
| 嫉妒发狂 | 男主看到女主和男二在一起 | ★★★★☆ |
| 语言反击 | 女主用最冷静的话说最扎心的话 | ★★★★☆ |
| 实力碾压 | 女主在专业/社交/商业上远超对手 | ★★★☆☆ |
| 众人震惊 | 旁观者对女主/男主变化的反应 | ★★★☆☆ |

### 爽点分布节奏
```
每800-1500字：至少一个小钩子（悬念/小冲突）
每2000-3000字：至少一个中爽点（打脸/反转）
每5000-8000字：至少一个大爽点（身份揭露/当众打脸/男主崩溃）
付费卡点前：必须是情绪最高潮或最大悬念
```

## 节奏控制

### 短篇节奏铁律

1. **300字法则**：开头300字内必须有第一个钩子
2. **无废话原则**：每个段落要么推情节，要么蓄情绪，否则删
3. **信息密度优先**：一句话能说清的不用两句
4. **情绪曲线不可平**：任何连续1000字内不能没有情绪波动

### 情绪曲线设计

```
虐女阶段情绪曲线（蓄力）：
高 ┃     ╱╲    ╱╲
   ┃    ╱  ╲  ╱  ╲     ╱← 最后一次伤害
   ┃   ╱    ╲╱    ╲   ╱
   ┃  ╱           ╲ ╱
低 ┃╱              ← 开始的甜蜜假象
   ┗━━━━━━━━━━━━━━━━━

追妻阶段情绪曲线（释放）：
高 ┃              ╱╲   ╱╲   ╱← 最高潮打脸
   ┃        ╱╲  ╱  ╲ ╱  ╲ ╱
   ┃  ╱╲  ╱  ╲╱    ╳    ╲
   ┃ ╱  ╲╱            ╲  ╲
低 ┃╱ 蜕变             ← 男主开始后悔
   ┗━━━━━━━━━━━━━━━━━
```

### 关键节奏节点（以3万字短篇为例）

| 节点 | 位置 | 内容 | 情绪 |
|------|------|------|------|
| 钩子开头 | 前300字 | 展示"我"的冲突/反差 | 好奇 |
| 关系建立 | 1000-3000字 | 我的付出与被忽视 | 心疼 |
| 第一次伤害 | 3000-5000字 | 他对我的冷漠/偏心 | 愤怒 |
| 伤害升级 | 5000-9000字 | 层层递进地虐我 | 积压 |
| 心死时刻 | 9000-12000字 | 我彻底放弃 | 心碎 |
| 蜕变开始 | 12000-15000字 | 我转身变强 | 期待 |
| 真相揭开 | 15000-18000字 | 我看到他的反常/崩溃反应 | 痛快 |
| 追妻打脸 | 18000-25000字 | 我的持续打脸+他追我 | 爽 |
| 终极高潮 | 25000-28000字 | 最大的打脸/他最卑微的时刻 | 极爽 |
| 和解/HE | 28000-30000字 | 我给出条件性和解 | 满足 |

## 常见变体与组合

### 题材组合公式

追妻火葬场可与其他热门标签组合，形成差异化：

| 组合 | 核心卖点 | 差异化点 |
|------|----------|----------|
| 追妻+替身 | 双重虐 + 双重反转 | 女主就是真白月光 |
| 追妻+先婚后爱 | 婚姻枷锁 + 迟来心动 | 从契约到真心的反转 |
| 追妻+重生 | 带记忆重来 + 主动改命 | 女主不再重蹈覆辙 |
| 追妻+马甲 | 隐藏身份 + 身份碾压 | 多重身份层层揭露 |
| 追妻+萌宝 | 亲子牵绊 + 追妻加码 | 孩子是催化剂 |
| 追妻+强强 | 势均力敌 + 双向追 | 不是弱者逆袭而是强者觉醒 |

### 创新方向
- **反向追妻**：女主追男主火葬场（女追男，男主心死后女主追回）
- **双男主追妻**：两个优质男性同时追，女主选择自己
- **女配视角**：从白月光/绿茶角度写，反套路
- **追妻后追夫**：先是男主追回女主，后是女主也有要追回的东西

## 禁忌与踩雷

### 绝对不能做的事

1. **男主不够渣**：前期男主如果只是轻微冷漠，后期追妻没有冲击力
2. **女主太圣母**：轻易原谅=爽感归零，必须让男主付出足够代价
3. **虐没有逻辑**：为虐而虐，人物行为不合理
4. **男二不够好**：男二如果不比男主更值得选，追妻没有紧迫感
5. **白月光洗白**：白月光必须得到惩罚，洗白会激怒读者
6. **BE结局**：追妻火葬场读者等的就是爽，BE等于诈骗
7. **节奏拖沓**：任何超过2000字没有情绪波动的段落都是毒药
8. **理性过头**：商业短篇是情绪产品，不要试图讲道理

### 常见翻车点

1. **前期虐太久**：超过全文40%还在虐，读者弃文
2. **追妻太容易**：女主三两句就原谅，读者暴怒
3. **男主不痛苦**：男主追妻像散步，读者感受不到"火葬场"
4. **蜕变不合理**：女主突然变强没有铺垫
5. **配角抢戏**：配角情节太多，主CP互动被稀释
6. **导语诈骗**：导语暗示的情节正文中没有兑现
