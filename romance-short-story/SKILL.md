# 女频商业短篇小说创作工作流

## 核心理念

女频商业短篇小说是**情绪商品**，不是文学作品。一切创作决策以"读者情绪体验"为最高准则。

**追妻火葬场是情感小说，情感是核心。** 身份、行为、设定全部可以替换，唯一不可替换的是两个人之间的情感张力。感情不是靠细节堆出来的，是靠**两个人在冲突事件中被迫面对彼此**撞出来的。每个感情节点必须由具体事件触发，必须有冲突，必须有画面。详见 [references/chase-wife-pattern.md](references/chase-wife-pattern.md) 的"情感驱动法则"

**铁律：锁定第一人称女主视角**。这不是风格选择，是商业逻辑——第一人称才有代入感，代入感是爽感的前提。不可切换第三人称，不可跳到男主视角，男主心理只能通过女主可观察的外部行为来呈现。番外可切男主视角。

创作顺序：**选题 → 人设 → 大纲 → 导语 → 正文 → 润色**

领域知识详见 [references/genre-knowledge.md](references/genre-knowledge.md)

## 工作流

**每一步输出前必须执行必检清单**，逐项验证。不通过的项目必须修改后才能输出，不能跳过。

### 第一步：选题策划

确定故事的核心卖点和差异化定位。

**必问用户**：
1. 目标平台（影响篇幅/风格/卡点）
2. 核心爽点类型（打脸/身份碾压/男主卑微/虐男）
3. 是否叠加其他标签（替身/先婚后爱/重生/马甲/萌宝）

**选题检查**：
- 核心冲突是否一句话能说清？
- 读者代入女主后是否会"想要看下去"？
- 是否有至少3个可预见的爽点场景？

选题详细套路见 [references/chase-wife-pattern.md](references/chase-wife-pattern.md) 的"常见变体与组合"章节

**第一步必检清单**（输出前逐项验证）：
- [ ] 相爱线：是否有至少3个"两人有真感情"的事件冲突？不是细节堆叠，是事件驱动的碰撞
- [ ] 副线：是否规划了至少2条由**第三方角色**驱动的副线？（男二/女二/外部势力，不是家人）
- [ ] 副线咬合：每条副线是否明确了在哪个节点改变主线走向？
- [ ] 逃离驱动力：女主为什么逃是否在男女主关系内部？是否有画面感的清算瞬间？是否有走得了的外部条件？
- [ ] 全部用"我"为主语，无"她/女主"

### 第二步：人设搭建

为故事的情绪功能服务，而非为文学性服务。

**所有输出必须使用第一人称"我"来描述女主的特质和经历**，因为这是读者代入的锚点。用"我"来写人设，等同于预演正文的视角。

**逻辑归因链（必须执行）**：对每个角色的每个关键行为，追问"为什么"至少3层，确保逻辑闭环。详见 [references/chase-wife-pattern.md](references/chase-wife-pattern.md) 的"逻辑归因链"章节

**东亚痛点优先级**：痛点必须扎在东亚人的神经上——恩债、被当工具、替身可替代、面子羞辱。不用西方式的"自我实现""尊严""寻找真我"。痛点必须有画面感。详见 [references/chase-wife-pattern.md](references/chase-wife-pattern.md) 的"东亚文化圈痛点体系"

**冲突节奏法则**：商业小说靠外部冲突推进，不靠内心戏。每个关键情节必须有画面感的具体动作/事件触发，不写抽象的情绪描述。情绪让读者自己感受。详见 [references/chase-wife-pattern.md](references/chase-wife-pattern.md) 的"商业小说冲突节奏法则"

**逃离驱动力**：女主为什么逃是整篇故事的发动机，必须在男女主关系内部、有画面感瞬间触发、外部条件允许她走。详见同上的"逃离驱动力设计"

**女主双面人设**（用"我"来写）：
- 前期面：我是什么样的人，我经历了什么真实损失，我为什么走不了（不是恋爱脑，是被困）
- 后期面：我变成了什么样，蜕变的现实基础是什么，我为什么让人向往
- 转折触发：什么事让我从前者切换到后者（必须有因果链）

**男主双面人设——渣苏法则**（从"我"的视角来写）：
- 渣面：他对我做了什么真实的伤害，我怎么感受到的
- 苏面：他身上有什么让"我"（和读者）恨他却无法完全厌恶的东西
- 渣的根源：他为什么渣——不止"控制"一种，还有背叛、误会、恐惧逃避、错位牺牲、自我欺骗、情感无能等。详见 [references/chase-wife-pattern.md](references/chase-wife-pattern.md) 的"渣苏的底层逻辑"
- 追的心理动力：他为什么追——不是"突然发现爱"，是某个具体事件击碎了他的认知框架
- 转折触发：我观察到了什么变化

**第一人称下呈现男主内心的技法**：不能跳视角，不能写"我猜他在想"，必须通过三层递进呈现——异常行为（逻辑断裂）→ 失控细节（框架维持不住）→ 自我暴露（说出连自己都意外的话）。详见 [references/chase-wife-pattern.md](references/chase-wife-pattern.md) 的"第一人称下如何呈现男主内心世界"

**配角功能表**：每个配角必须明确其情绪功能，并从"我"的视角写一句这个角色对我的意义

人设模板与原型详见 [references/chase-wife-pattern.md](references/chase-wife-pattern.md) 的"人设体系"章节

**第二步必检清单**（输出前逐项验证）：
- [ ] 第一人称：全部用"我"写女主，无"她/女主"
- [ ] 男主内心：呈现方式是否走三层递进（异常行为→失控细节→自我暴露），而非"我猜他在想"/"他的眼神告诉我"
- [ ] 男主渣苏：渣的根源是否具体（不是"他天生坏"/"他不懂爱"）？苏的来源是否和渣同源？
- [ ] 追的心理动力：是否有完整归因链（转变前→击碎事件→认知崩塌→重建→追），不是"突然发现爱"
- [ ] 痛点画面：每个伤害/心疼的描述是否有具体画面，不是抽象情绪词
- [ ] 事件冲突：每段感情描述是否由事件触发，不是细节堆叠

### 第三步：大纲构建

按情绪曲线逆向设计，先定爽点再填充过程。

**大纲结构**（以3万字短篇为例，全部用"我"为主语）：

```
一、虐女期（30-40%，约9000-12000字）
   - 建立关系：我的付出 [1000-3000字]
   - 展现冷漠：他如何伤害我 [3000-5000字]
   - 伤害升级：层层递进 [5000-9000字]
   - 心死离开：我的最高虐点 [9000-12000字]

二、觉醒期（20-30%，约6000-9000字）
   - 我的蜕变 [12000-15000字]
   - 他发现真相（我从外部观察到的反应） [15000-18000字]
   - 追妻开始（我如何应对） [18000-21000字]

三、火葬场（30-40%，约9000-12000字）
   - 持续打脸（我的反击） [21000-25000字]
   - 终极高潮 [25000-28000字]
   - HE/条件和解 [28000-30000字]
```

**大纲必须包含**：
1. 每段字数预估
2. 每段核心情绪（心疼/愤怒/期待/爽/极爽/满足）
3. 至少5个具体爽点场景
4. 付费卡点位置
5. 导语对应的情节位置
6. **多线交织表**：2万字以上必须规划至少2条由第三方角色驱动的副线（男二/女二/外部势力），明确每条副线在什么节点影响主线走向。详见 [references/chase-wife-pattern.md](references/chase-wife-pattern.md) 的"多线交织架构"

**第三步必检清单**（输出前逐项验证）：
- [ ] 第一人称：全部用"我"为主语
- [ ] 情感先行：每段是否先明确"这段的情感是什么"，再写事件
- [ ] 事件冲突：每个情节节点是否由具体事件驱动，不是抽象过渡
- [ ] 副线变量：每5000字区间是否至少有一条副线在制造变量
- [ ] 章末钩子：每章结尾是否标注了钩子类型和具体断法
- [ ] 卡点位置：付费卡点是否断在情绪最浓处

### 第四步：导语撰写

导语是生死线，3秒定点击，200字定存留。

**导语公式**（选一，均用第一人称"我"）：
1. 对话切入式：[我决绝的话] + [男主的意外反应] + [悬念]
2. 情境反差式：[我的卑微处境] + [震惊转折] + [翻转预告]
3. 时间紧迫式：[紧迫情境] + [两难选择] + [情绪爆发]

**导语铁律**：
- 不超过200字
- 有对话或具体动作
- 有反转/悬念
- 不剧透结局

导语写法与示例详见 [references/chase-wife-pattern.md](references/chase-wife-pattern.md) 的"导语写法"章节

### 第五步：正文创作

按大纲逐章写作，遵循以下节奏规则：

**节奏铁律**：
- 前300字必须有第一个钩子
- 每800-1500字至少一个小钩子
- 每2000-3000字至少一个中爽点
- 每5000-8000字至少一个大爽点
- 任何连续1000字不能没有情绪波动

**写作风格**：
- **第一人称"我"**：全文锁定女主视角，不跳视角
- 短句为主，长句拆分
- 对话推进情节，减少大段描写
- 情绪用动作/细节展现，不直接说"我很难过"
- 场景切换快，不拖沓
- 每章结尾留钩子
- 男主心理通过外部可观察行为呈现（他看向我的眼神/他反常地出现/他的手在抖），不直接写"他想"

**禁忌**：
- 不写大段环境描写
- 不写冗长内心独白
- 不写无关配角戏份
- 不写平淡过渡段落
- 不写说教式议论
- 不跳到男主/配角视角（番外除外）

钩子与爽点设计详见 [references/chase-wife-pattern.md](references/chase-wife-pattern.md) 的"钩子与爽点设计"章节

**第五步必检清单**（每章写完后逐项验证）：
- [ ] 第一人称：全文"我"，无"她/女主"指代女主
- [ ] 无内心戏：没有"我猜他在想"/"他的眼神告诉我"/"我感到自己失去了什么"，只有动作和事件
- [ ] 男主内心呈现：通过三层递进（异常行为→失控细节→自我暴露），不是直接描写
- [ ] 章末钩子：每章结尾有具体钩子，不是情绪收束
- [ ] 画面感：每段关键情节3秒内能脑补画面

### 第六步：润色与检查

**商业化检查清单**（逐项验证）：

**导语/标题**：
- 标题含2个以上热门标签词
- 导语200字内、有对话/动作、有反转/悬念

**节奏**：
- 无超过2000字的情绪平淡区
- 虐女阶段不超过全文40%

**视角**：
- 全文第一人称女主视角
- 无任何视角跳转（男主/配角内心独白）
- 男主心理变化全部通过女主可观察行为呈现

**人设**：
- 女主前期值得同情、后期值得追捧
- 男主前期足够渣、后期足够痛
- 白月光/绿茶结局被惩罚

**结局**：
- HE或条件性和解
- 女主不轻易原谅
- 男主付出足够代价

**合规**：
- 无敏感内容，虐待场景模糊处理
- 法律程序基本合规

**情感完整性**：
- 相爱线：全文是否有足够的事件冲突证明两人有真感情？
- 堵住线：爱走不通的原因是否全部由具体事件暴露？
- 拉扯线：追妻阶段每个节点是否由事件驱动，不是重复的"他求我拒"？
- 副线效果：第三方角色是否在关键节点改变了主线走向？

完整检查清单见 [references/platform-rules.md](references/platform-rules.md) 的"商业化写作检查清单"章节

## 输出格式

所有创作成果输出为 Markdown 格式，按以下结构组织：

```
{故事名}/
├── 选题卡.md      # 选题决策记录
├── 人设表.md      # 完整人物设定
├── 大纲.md        # 分章大纲
├── 导语.md        # 导语文案（含标题候选）
├── 正文/          # 按章节存放
│   ├── 第01章.md
│   ├── 第02章.md
│   └── ...
└── 润色记录.md    # 修改日志
```

## 快速启动

当用户说"帮我写一个追妻火葬场短篇"时，直接按工作流从第一步开始。

如果用户已有部分创作（如只有人设或只有大纲），从对应步骤接入，不必从头开始。
