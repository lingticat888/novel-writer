# 女频商业短篇小说创作工作流

## 核心理念

女频商业短篇小说是**情绪商品**，不是文学作品。一切创作决策以"读者情绪体验"为最高准则。

**铁律：锁定第一人称女主视角**。这不是风格选择，是商业逻辑——第一人称才有代入感，代入感是爽感的前提。不可切换第三人称，不可跳到男主视角，男主心理只能通过女主可观察的外部行为来呈现。番外可切男主视角。

创作顺序：**选题 → 人设 → 大纲 → 导语 → 正文 → 润色**

领域知识详见 [references/genre-knowledge.md](references/genre-knowledge.md)

## 工作流

### 第一步：选题策划

确定故事的核心卖点和差异化定位。

**必问用户**：
1. 目标平台（影响篇幅/风格/卡点）
2. 核心爽点类型（打脸/身份碾压/男主卑微/虐男）
3. 是否叠加其他标签（替身/先婚后爱/重生/马甲/萌宝）

**选题检查**：
- 核心冲突是否一句话能说清？
- 读者代入女主后是否会"想要看下去"？
- 是否有至少3个可预见的爽点场景？

选题详细套路见 [references/chase-wife-pattern.md](references/chase-wife-pattern.md) 的"常见变体与组合"章节

### 第二步：人设搭建

为故事的情绪功能服务，而非为文学性服务。

**女主双面人设**：
- 前期面：让读者心疼的特质（深情/隐忍/被忽视的闪光点）
- 后期面：让读者向往的特质（蜕变/独立/碾压级实力）
- 转折触发：什么事件让她从前期面切换到后期面

**男主双面人设**：
- 前期面：让读者恨的特质（冷漠/偏心/轻贱）
- 后期面：让读者解气的特质（卑微/痛苦/求而不得）
- 转折触发：什么事件让他意识到感情/发现真相

**配角功能表**：每个配角必须明确其情绪功能（制造冲突/推动反转/制造对比/替读者骂人）

人设模板与原型详见 [references/chase-wife-pattern.md](references/chase-wife-pattern.md) 的"人设体系"章节

### 第三步：大纲构建

按情绪曲线逆向设计，先定爽点再填充过程。

**大纲结构**（以3万字短篇为例）：

```
一、虐女期（30-40%，约9000-12000字）
   - 建立关系：女主付出 [1000-3000字]
   - 展现冷漠：男主伤害 [3000-5000字]
   - 伤害升级：层层递进 [5000-9000字]
   - 心死离开：最高虐点 [9000-12000字]

二、觉醒期（20-30%，约6000-9000字）
   - 女主蜕变 [12000-15000字]
   - 男主发现真相 [15000-18000字]
   - 追妻开始 [18000-21000字]

三、火葬场（30-40%，约9000-12000字）
   - 持续打脸 [21000-25000字]
   - 终极高潮 [25000-28000字]
   - HE/条件和解 [28000-30000字]
```

**大纲必须包含**：
1. 每段字数预估
2. 每段核心情绪（心疼/愤怒/期待/爽/极爽/满足）
3. 至少5个具体爽点场景
4. 付费卡点位置
5. 导语对应的情节位置

### 第四步：导语撰写

导语是生死线，3秒定点击，200字定存留。

**导语公式**（选一，均用第一人称"我"）：
1. 对话切入式：[我决绝的话] + [男主的意外反应] + [悬念]
2. 情境反差式：[我的卑微处境] + [震惊转折] + [翻转预告]
3. 时间紧迫式：[紧迫情境] + [两难选择] + [情绪爆发]

**导语铁律**：
- 不超过200字
- 有对话或具体动作
- 有反转/悬念
- 不剧透结局

导语写法与示例详见 [references/chase-wife-pattern.md](references/chase-wife-pattern.md) 的"导语写法"章节

### 第五步：正文创作

按大纲逐章写作，遵循以下节奏规则：

**节奏铁律**：
- 前300字必须有第一个钩子
- 每800-1500字至少一个小钩子
- 每2000-3000字至少一个中爽点
- 每5000-8000字至少一个大爽点
- 任何连续1000字不能没有情绪波动

**写作风格**：
- **第一人称"我"**：全文锁定女主视角，不跳视角
- 短句为主，长句拆分
- 对话推进情节，减少大段描写
- 情绪用动作/细节展现，不直接说"我很难过"
- 场景切换快，不拖沓
- 每章结尾留钩子
- 男主心理通过外部可观察行为呈现（他看向我的眼神/他反常地出现/他的手在抖），不直接写"他想"

**禁忌**：
- 不写大段环境描写
- 不写冗长内心独白
- 不写无关配角戏份
- 不写平淡过渡段落
- 不写说教式议论
- 不跳到男主/配角视角（番外除外）

钩子与爽点设计详见 [references/chase-wife-pattern.md](references/chase-wife-pattern.md) 的"钩子与爽点设计"章节

### 第六步：润色与检查

**商业化检查清单**（逐项验证）：

**导语/标题**：
- 标题含2个以上热门标签词
- 导语200字内、有对话/动作、有反转/悬念

**节奏**：
- 无超过2000字的情绪平淡区
- 虐女阶段不超过全文40%

**视角**：
- 全文第一人称女主视角
- 无任何视角跳转（男主/配角内心独白）
- 男主心理变化全部通过女主可观察行为呈现

**人设**：
- 女主前期值得同情、后期值得追捧
- 男主前期足够渣、后期足够痛
- 白月光/绿茶结局被惩罚

**结局**：
- HE或条件性和解
- 女主不轻易原谅
- 男主付出足够代价

**合规**：
- 无敏感内容，虐待场景模糊处理
- 法律程序基本合规

完整检查清单见 [references/platform-rules.md](references/platform-rules.md) 的"商业化写作检查清单"章节

## 输出格式

所有创作成果输出为 Markdown 格式，按以下结构组织：

```
{故事名}/
├── 选题卡.md      # 选题决策记录
├── 人设表.md      # 完整人物设定
├── 大纲.md        # 分章大纲
├── 导语.md        # 导语文案（含标题候选）
├── 正文/          # 按章节存放
│   ├── 第01章.md
│   ├── 第02章.md
│   └── ...
└── 润色记录.md    # 修改日志
```

## 快速启动

当用户说"帮我写一个追妻火葬场短篇"时，直接按工作流从第一步开始。

如果用户已有部分创作（如只有人设或只有大纲），从对应步骤接入，不必从头开始。
